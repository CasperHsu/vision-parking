範圍：以視界學院（新竹市北區中正路107號）為中心，顯示範圍可用上方滑桿調整（100 m〜1 公里，預設 500 m），只列官方 API 有即時資料的停車場，依距離由近到遠排列；步行時間以每分鐘 80 公尺、路線係數 1.3 估算。

資料來源：新竹市政府交通處停管科開放資料（hispark.hccg.gov.tw，與官方「新竹市好停車」App 相同來源）；YouBike 資料來源：交通部 TDX 運輸資料流通服務；天氣資料來源：Open-Meteo.com（CC BY 4.0，每 10 分鐘更新，建議僅供參考）；地圖圖資 © OpenStreetMap 貢獻者。

即時性說明：本頁每 20 秒自動更新，但市府系統每筆停車場資料通常約 1〜3 分鐘才寫入一次，實測偶爾會出現 20 分鐘以上沒有寫入的情況，且尖峰時段數字可能瞬間大幅變動，因此畫面數字與現場實況可能有落差。每張卡片的「官方更新」欄位即為市府系統寫入該筆資料的時間，標題下方也會顯示「市府資料 N 分前」——若這個數字持續變大，代表是市府端暫停更新，不是本頁故障；超過 15 分鐘會自動出現提醒。

免責聲明：本頁面由視界學院整理提供，僅供行前參考。車位數量隨時變動，實際以現場為準；視界學院不保證資料之即時性、正確性與完整性，亦不對使用本頁面資訊所生之任何損害負責。

開源聲明：本系統已在 GitHub 開源（CasperHsu/vision-parking，MIT 授權）——歡迎自由取用，改成你的店、你的城市。若你部署了自己的版本，歡迎到 GitHub 開個 issue 或透過上方 LINE 告訴我們；這不是授權義務，但知道這個點子在別的地方發芽，是我們最開心的事。
